Definitions
sites_found
production LLM sites: API calls (chat, responses, messages, embeddings, images...) and framework model constructions; tests/examples/evals excluded
migrated
sites whose traffic goes to Router when RAMP_ROUTER_API_KEY is set (client patched, surface served by Router, model in catalog or chosen at runtime)
handoff
sites that need an agent-made code change (other-vendor SDK whose model Router serves, raw HTTP, other gateways)
kept
sites that stay on their provider by design (no Router endpoint, e.g. embeddings; or another vendor's endpoint)
flagged
sites Router could serve but the tool does not move automatically (unmapped model, beta API, server-side state)
callsite_coverage
migrated / sites_found
weighted_coverage
migrated / Router-eligible sites (generation surfaces Router can serve)
tests_before/after
the repo's own offline test suite (or typecheck where it has none), Router off, before vs after migrating
sim_valid_pct
valid / total requests at router-sim from (a) the repo's tests run with Router on and (b) one synthetic replay per migrated site
live_success_pct
same replay against api.router.com (null when not run)
